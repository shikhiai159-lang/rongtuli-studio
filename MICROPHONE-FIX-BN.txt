RongTuli Studio 1.0.5 — Microphone diagnostic update

এই আপডেটে Android APK-এর জন্য একমাত্র HTML entry হলো www/index.html। Native APK-তে service worker নিবন্ধন বন্ধ করা হয়েছে, যাতে পুরোনো cached HTML থেকে আগের error message না আসে। PWA service worker cache key v8 করা হয়েছে।

Android manifest-এ RECORD_AUDIO এবং MODIFY_AUDIO_SETTINGS থাকা নিশ্চিত করতে build workflow চালায় scripts/patch-android-mic-permission.py। Capacitor-এর BridgeWebChromeClient getUserMedia-এর AUDIO_CAPTURE অনুরোধে runtime permission নিয়ে থাকে।

গুরুত্বপূর্ণ: সোর্স/ZIP পরীক্ষা করা আর বাস্তব ফোনে APK পরীক্ষা করা এক জিনিস নয়। এই ZIP-এ APK আগে থেকে build করা নেই। GitHub Actions-এ নতুন APK তৈরি করে পুরোনো অ্যাপ আনইনস্টল করে নতুন APK ইনস্টল করুন। নতুন APK-তেও সমস্যা থাকলে exact error name (NotAllowedError / NotReadableError / GET_USER_MEDIA_UNAVAILABLE) দেখাবে; সেটি দেখে পরবর্তী সংশোধন করতে হবে।
