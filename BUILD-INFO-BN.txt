RongTuli Studio Android source — v1.1.0 English Premium Recorder

This ZIP contains source files, not a compiled APK. Build using GitHub Actions → Build Android APK → Run workflow, then download the APK artifact.

English UI, updated app branding, recording timer and explicit Stop & Save control, and basic SEO metadata have been added. Bengali characters/words remain in Bengali where they are the lesson content.

Static validation can be performed here, but no Android SDK or physical device is connected, so a real-device microphone test is not claimed.
